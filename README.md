# Agent Storage Auditor

**Find out how much disk space your AI agents use, where their files live, and what each folder is for.**

A read-only, on-demand scanner with a portable agent skill and a local MCP extension. Designed for Codex, Claude Code, Cursor, Gemini CLI, GitHub Copilot local agents, OpenCode, and Claude Desktop.

## Quick start

1. Download and extract the ZIP. The scanner requires **Node.js 22 or newer**.
2. Copy the extracted `agent-storage-auditor` folder into your assistant's skill directory, following the [installation guide](SETUP.md).
3. Ask: **“Show how much storage my AI agents use, where their files are, and what each folder contains.”**

For Claude Desktop, install the `.mcpb` file and choose the folders it is allowed to scan. No API key is required. Your assistant's filesystem permissions still apply.

Standalone use from the extracted folder:

```sh
node dist/cli.mjs discover_agents
node dist/cli.mjs scan_storage --format markdown
node dist/cli.mjs scan_storage --root "/absolute/path/to/workspace" --format markdown
```

Windows paths work too; put paths containing spaces in quotes. Local MCP clients can run `dist/server.mjs` with permitted folders as arguments; see [SETUP.md](SETUP.md).

## What you get

- Known agent-folder discovery and optional user-selected workspaces.
- Logical file sizes, full paths, file counts and purpose descriptions.
- Largest folders and files, with nested totals clearly identified.
- Confidence labels for inferred folder purposes.
- Explicit coverage warnings for inaccessible files, links, changing files and scan limits.
- Three MCP tools: `discover_agents`, `scan_storage`, and `describe_folder`.

The scanner reads filesystem metadata, not credentials, conversation bodies or file contents. It has no deletion operations, telemetry or background monitoring. Metadata sent back to an assistant is subject to that assistant's data handling policies.

## Compatibility and limitations

Designed for Windows, macOS and Linux. Windows tests and packaged MCP protocol tests passed during initial development. macOS/Linux and assistant-specific UI installation testing are documented separately in [VALIDATION.md](VALIDATION.md); the included GitHub Actions workflow tests all three operating systems with Node 22 and 24.

Storage measurements are **logical bytes, not RAM or exact physical disk allocation**. Agent-associated folders do not prove that every file was generated by AI. The scanner does not determine whether a file is safe to delete. Browser-only agents require a local connection.
